Questions, answered

What if the old website is already gone?

Paste a Wayback Machine snapshot as the before URL — ReelForge films archives just like live sites.

Do I need to record or edit anything?

No. ReelForge opens both sites in a real browser, films a scripted camera tour, and composes the full video — intro, labels, transition, end card, music bed.

Can I use my client’s branding?

Yes — brand kits store each client’s logo, colors, CTA and end-card message, and apply automatically to new projects.

Where can I post the videos?

Exports are standard MP4s sized for Instagram Reels, TikTok, Facebook, LinkedIn or square feeds. Facebook Pages can be posted to directly; other networks via download or Make.com.

Does it work on animated / WebGL sites?

Yes — the filming pipeline captures the browser’s real output, including three.js scenes, scroll animations and video backgrounds.
